# 🎬 Elflix

A modern movie discovery web application built as part of a Frontend Developer Technical Test for Elemes Group.

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`VITE_TMDB_API_KEY`
`VITE_TMDB_BASE_URL`
`VITE_TMDB_IMAGE_URL`

## Run Locally

Clone the project

```bash
  git clone https://github.com/yohanessahrul/elemesflix.git
```

Go to the project directory

```bash
  cd elemesflix
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```

## Tech Stack

React, Vite, Typescript, Tanstack-Query, Zustand, Axios
